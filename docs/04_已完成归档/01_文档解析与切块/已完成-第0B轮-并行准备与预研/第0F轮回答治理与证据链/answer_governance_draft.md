## 1. 完整意图识别

命中以下任一模式时视为「完整性敏感」问题：

- `完整` / `全部` / `所有步骤` / `有哪些步骤`
- `分别说明` / `逐一` / `按顺序`
- `端到端` / `从…到…`

处理：

1. 回答前用检索证据覆盖度对照 `required_facts` / 目标章节锚点。
2. 覆盖不足时 **禁止** 使用：`完整流程`、`全部如下`、`至此完成全部步骤` 等强断言。
3. 部分回答必须显式列出缺失部分（沿用现有 partial 句式，并要求点名缺失主题）。

---

## 2. 回答策略矩阵

| answerability | 策略 |
|---|---|
| `full` | 覆盖必需事实并引用；可使用「如下」仅当证据齐全 |
| `partial` | 先答有据部分 + 列出未覆盖方面；禁强完整断言 |
| `conflict` | **必须**同时列出冲突取值与来源编号；禁止静默二选一 |
| `none` | 原样拒答：`当前知识库中未查询到相关内容。` |

---

## 3. 冲突治理

对同一配置键、端口、路径、默认值：

1. 从高相关证据中抽取候选值集合。
2. 若集合大小 > 1：回答中并列展示，并提示「请核对原文」。
3. 不得只保留一个值。
4. 冲突样本进入人工语料治理清单（审计已输出 `conflict_candidates`）。

判定提示词（评测侧已用正则近似）：`冲突` / `不一致` / `两处` / `分别` / `核对`。
