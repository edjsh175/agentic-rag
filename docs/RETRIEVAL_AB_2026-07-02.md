## Reranker 结论

- 本地模型可以加载和完成小样本推理。
- 标准集在限制为 2 个 CPU 线程后运行 20 分钟仍未完成，未产生可用质量指标。
- 当前 CPU 部署不满足同步在线检索的延迟要求，因此生产配置保持 `reranker.enabled = false`。
- 如需继续验证，应使用 GPU 或离线批处理环境，通过 `run_retrieval_ab.py` 分策略续跑。
