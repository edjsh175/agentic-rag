## 6. 每轮共同约束

```text
1. 停止后端与其他占用 chroma_db / rag_relational.db 的进程后再做正式库写入
2. LLM / profile_sync / product_backbone_seed 候选禁止 --approve-all
3. apply 须 --confirm-db-path / --confirm-batch / --confirm-backup
4. 每轮开始前 audit，结束后 quality --graph
5. 规则与 LLM 不得产出与 seed:product_backbone 矛盾的边
6. 轮次报告验收通过后，将一次性产物迁入 data/archive/，勿与 live 真源混放
7. --include-llm 禁止空 stub；Ollama 不可达须 fail-fast
8. 局域网 Ollama 访问须规避系统代理（NO_PROXY / 系统旁路）
```
