1. **锚点 chunk 过滤（C）未修复 B 的回退**：C 与 B 在 Hit@3、分题结果上几乎一致；**graphrag-005 仍失败**。
2. **开图仍对配置题有帮助**：graphrag-008「值域映射约束」A 未命中，B/C 均满分。
3. **开图新增 2 题回退**（相对 A）：
   - **graphrag-005**：「StampTools 工具概述…」— 图块把「瓦片级别」等细则顶进前三，概述金标被挤出。
   - **graphrag-020**：「UV展开错误如何排查」— 金标是错误说明块；开图后前三变成管线线表等无关 Pipeline 邻居。

## 业务解读

- 问题**不在**「再多抽一批关系」；而在 **扩召回太宽 + 融合排序** 对「概述类 / 错误类」题不友好。
- **单靠 `anchor_chunk_filter_enabled` 不够**；005/020 的 canonical 是 StampTools / UV展开错误，过滤规则未挡住「同产品其他章节」挤前排。
