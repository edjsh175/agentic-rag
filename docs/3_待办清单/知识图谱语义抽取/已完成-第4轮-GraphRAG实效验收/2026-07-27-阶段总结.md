## 3. 核心发现

1. **开图有用**
   配置类题（如「值域映射约束」）关图易偏到邻居章节，开图可拽回正确证据。

2. **主因不是「关系太少」**
   更像扩召回过宽：同工具邻居块挤前排，伤「工具概述」「报错排查」题（005 / 020）。

3. **过滤 / allowlist alone 压不住回退**
   A/B/C/D 对照后，005/020 在开图或 allowlist 下仍相对关图回退。

4. **融合上限对症**
   - 全开图 + 上限：Hit@3 **17→18/20**；005/020 回退消失；008 增益保留；R@3 约 **51%→57%**
   - Allowlist + 上限：005 修好，**020 仍可能漏**（改写偏锚，另层问题）
