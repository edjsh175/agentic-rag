# 图谱生产部署建议

- **记录日期**：2026-07-27（第 4 轮 A/B 后更新）
- **适用范围**：第 3 轮补完成、第 4 轮 GraphRAG 检索 A/B 已出结论后的生产口径

## 1. 推荐配置口径

```ini
# config-prod.ini（生产模板，建议）
[graph_retrieval]
enabled = false
query_rewrite_enabled = false
anchor_chunk_filter_enabled = false
anchor_graph_chunk_enabled = false

[graph_extraction.llm]
enabled = false
```

```ini
# 本地体验（可选）
[graph_retrieval]
enabled = true                 # 第 4 轮已证明 StampTools 专项集有提升
query_rewrite_enabled = true   # 可与主干锚定改写叠加；注意成本
anchor_chunk_filter_enabled = true
anchor_graph_chunk_enabled = true   # 仅 allowlist（如 PipelineBuilder）时相对可控
```

业务含义：

1. **第 4 轮证明「开图能增强检索」≠「生产必须默认开」**。专项/扩测均 PASS；`missing_evidence` 已清零，但仍有金边缺口与 1 条非法边。
2. `graph_extraction.llm.enabled = false`：生产常驻不自动全库 LLM；维护窗口用 CLI `--include-llm`。
3. Intent 评分（alias / `different_from`）不依赖 `graph_retrieval.enabled`，关图时仍可读正式库做加减分。

## 2. 维护窗口 SOP

| 阶段 | 要求 |
|------|------|
| 执行前 | 停止占用 `chroma_db` / `rag_relational.db` 的写进程 |
| 备份 | timestamped 备份；保护 `pre_round3` / R5–R7 关键回滚点 |
| 扩抽 | 仅 `--doc-category` 分批；禁止无差别「其他」盲抽 |
| 审批 | LLM batch 禁止 `--approve-all`；apply 须 confirm 三件套 |
| 验收 | audit / quality / Task81；开图前重跑 `scripts/compare_graph_rag_eval.py` |

## 3. 风险说明

| 风险 | 说明 | 控制方式 |
|------|------|----------|
| 邻域噪声 | 图扩召回把同工具其他节挤进 topK | 锚点过滤 / allowlist；观察 Hit 回退 |
| 证据债 | missing_evidence / 缺金边 | **missing_evidence=0（已清）**；仍缺 2 金边 + 1 illegal；生产默认关，补齐后再议默认 on |
| LLM 成本 | 全库盲抽耗时长 | 只按类目维护窗口执行 |
| 回滚误操作 | 覆盖错误备份 | 保留 R5–R7 / pre_round3 备份 |

## 4. 上线判定

1. 第 3 轮补完成：图谱可作为检索增强**候选**。
2. 第 4 轮检索 A/B **通过**：可写入交付结论「图谱对配置/定义/流程类问题可增强检索」。
3. **生产默认 on**：仍 **未批准**；需 quality 历史债收敛 + 回退噪声可控后再开。
