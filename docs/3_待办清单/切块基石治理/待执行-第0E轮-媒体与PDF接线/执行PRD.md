# 待执行：第 0E 轮——媒体与 PDF 接线

## 阶段状态

- 状态：拆分执行
- 当前执行范围：PDF 文本版面解析及统一 Canonical 接线
- 延期范围：OCR、图片、视频、文档内嵌媒体和 PDF 表格结构化

## 本轮执行

1. 使用 PDF 原生文本和版面信息恢复阅读顺序、标题、段落、页码及跨页血缘。
2. 将可靠文本输出为统一 Canonical Element，并复用 Profile Builder 和 Common Finalizer。
3. 无文本页面不生成占位 Chunk，只记录 `PDF_PAGE_REQUIRES_OCR`。
4. 同一 PDF 中的可靠文本页面可以继续进入隔离验收；待 OCR 页面保持可追踪。

## 后续待办

- 扫描 PDF 和图片 OCR；
- 图片、视频及内嵌媒体的视觉描述和媒体哈希；
- PDF 表格结构化恢复；
- OCR 置信度、版面证据、隔离评测和正式写库门禁。

延期边界和后续准入条件见：[OCR 与媒体处理延期决定](../2026-07-16-OCR与媒体处理延期决定.md)。

## 安全边界

- 本轮不调用 OCR 或视觉模型；
- 不将占位文本写入知识库；
- 不直接写正式 Chroma；
- 正式应用继续受 0G、FR-10 和 Go 清单控制。
