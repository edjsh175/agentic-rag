## 2. ✅ 已完全实现并上线的核心功能

### A. 文档解析与切块基石
- **多格式支持**：PDF、Office、文本、Markdown、Excel 的自动化解析与切块。
- **解析层级规范**：引入 `section_path` 投影，实现统一的 Canonical 格式，清除旧版伪章节错乱的漏洞。
- **数据一致性校验**：Chroma 向量库与 SQLite 关系表字段级一致性比对和受控自动重建能力。

### B. 知识图谱与语义关系抽取
- **官方主干校验**：基于 `product_relation_backbone.json`（175条主干边）的边界约束，防范图谱漂移。
- **双通道抽取**：支持基于显式规则提取与大模型（LLM）小范围/按类目的精准语义关联抽取。
- **经验产品化早拒**：构建泛名实体黑名单，并在大模型抽取前置阶段增加非法类型边（如不合规范的关系对）的早拒逻辑。

### C. 多策略检索与融合
- **检索路径归一**：同步、异步和流式路径均统一走 `RetrievalStrategy` 融合模型。
- **融合上限与压噪**：实现 `max_graph_only_slots=1` 与文本保护逻辑，压制因开图引入的无关章节噪声。
- **证据包 (EvidencePack)**：提供 `POST /admin/qa-debug` 接口，输出包含 `cited`（已用引用）、`retrieved_uncited`（召回未用）、`gaps`（完整度缺失）及 `conflicts`（配置冲突并列）的四栏审计面板。
